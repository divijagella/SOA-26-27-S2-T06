# AegisCore — API Security Monitoring

A standalone recreation of an API security monitoring dashboard.

## Run
No build tools are required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

## Included
- Security overview dashboard
- Request activity visualization
- Protected API endpoints
- Threat detection list
- Security logs
- Responsive layout
- Interactive navigation and refresh/add/clear actions

This is an independent recreation and is not the original Base44 source code.
